# F1 Championship Hub

Una aplicación web moderna e interactiva para seguir el campeonato mundial de Fórmula 1 en tiempo real (simulado), desarrollada con React, Tailwind CSS y diseño responsivo optimizado para modo oscuro.

## Características Principales

- **Cuenta Atrás en Vivo**: Widget principal que muestra el tiempo restante exacto para el próximo Gran Premio, circuito y horario local.
- **Clasificaciones de Pilotos y Constructores**: Tablas detalladas con barras de progreso animadas basadas en la puntuación actual de la temporada.
- **Resumen del Último GP**: Podio de ganadores, tiempos y vuelta rápida.
- **Feed de Noticias**: Artículos recientes del mundo motor.
- **Calendario Interactivo**: Filtros por estado (disputados y próximos) con buscador integrado por circuito o nombre de carrera.

## Tecnologías Utilizadas

- HTML5 & JSX (React 18 vía CDN)
- Tailwind CSS (Configuración personalizada mediante CDN)
- Lucide Icons (Iconografía moderna)

## Instalación Local

1. Clona este repositorio.
2. Abre el archivo `index.html` en cualquier navegador web moderno.
3. ¡Disfruta de toda la emoción de la Fórmula 1!
